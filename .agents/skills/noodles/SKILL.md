# Noodles Skill

Noodles is an AI-powered code visualization and call graph analysis tool designed to trace execution flows, dependencies, and architectural components.

## Capabilities
- Analyze local repositories to extract execution flows and module dependencies.
- Map entry points, API routes, middleware, and component interactions.
- Provide structured explanations of full-stack execution flows.
